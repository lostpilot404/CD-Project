Overview

CodeTrace parses a C-like language with its own canonical LR(1) parser generator and analyses the result: control-flow graphs, reaching definitions, liveness, definite assignment, taint propagation, a typed program dependency graph and program slices.

Analyze Code

The text is analysed as data. Nothing in it is executed, imported or written to disk.

Rule Editor

Security rules are written in a small declarative language that CodeTrace parses with its own LR(1) machinery and validates before use. Rules are untrusted input: they can declare functions, contexts and severities, and they can never execute code.
